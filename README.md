# Vue 3 + Vite

This template should help get you started developing with Vue 3 in Vite. The template uses Vue 3 `<script setup>` SFCs, check out the [script setup docs](https://v3.vuejs.org/api/sfc-script-setup.html#sfc-script-setup) to learn more.

Learn more about IDE Support for Vue in the [Vue Docs Scaling up Guide](https://vuejs.org/guide/scaling-up/tooling.html#ide-support).

ACTIVITAT 1

1. El primer que he fet a sigut anar a la carpeta del meu projecte en local i fer un **git init**
2. Despres he anat a github he creat un repositori i he copiat la seva URL
3. Un cop he fet el repositori he anat a la terminal i he afegir el meu repositori de github com a repositori remot amb la comanda **git remote add i la URL del meu repositori**
4. I ara per pujar el meu projecte a github he possat la comanda **git add .**, **git commit -m "_Text del commit_"** i **git push -u origin main** i ya s'han pujat els arxius
5. Quan he fet el **git push -u origin main** m'ha demanat el meu usuari de github i una contraseña que es un tokken del meu usuari, aixi que le tingut que crear
6. A continuació al github he tingut que cre anat a configuració --> Developer Settings --> Personal acces tokens i aqui he creat el meu tokken personal per poder pujar els arxius a github
